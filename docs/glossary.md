# FARSPACE Glossary

| Term | Definition |
|---|---|
| Empire | Political actor controlling colonies, fleets, research, and diplomacy state. |
| Major empire | Fully simulated core empire participant (player or AI) in current game state. |
| Minor faction | Smaller non-major actor concept; implementation status needs verification. |
| Sector | Galaxy region grouping multiple star systems. |
| Star system | Single star node with planets, fleets, and colony interactions. |
| Planet | Colonizable world entry in a star system with class/size/survey/resource traits. |
| Colony | Owned planetary settlement with population, queue, economy outputs, and role. |
| Pop | Colony population count used by economy/yield systems. |
| Job | Planned explicit labor assignment unit; not fully implemented yet. |
| Structure | Built installation affecting colony output or capability. |
| Orbital structure | Space-based colony installation (e.g., shipyard) occupying orbital slots. |
| Ship design | Predefined ship archetype record defining cost/stats/role/required tech. |
| Fleet | Mobile military/support unit group at a star or in transit. |
| Survey | Science-ship mission that reveals planet intel and enables colonization decisions. |
| Hyperspace lane | Deterministic route edge between stars used for faster lane travel when unlocked. |
| Trade/supply connection | Colony network connectivity state affecting yields and isolation penalties. |
| Turn report | Per-turn outcomes shown through event log/summary signals. |
| Victory condition | Rule that defines game completion and winner; planned system. |

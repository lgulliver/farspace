Reading Guide

  • Implemented now: tech already has active gameplay effect or unlock.
  • Future hook: tech is visible in tree and planning docs, but some downstream mechanics are roadmap-facing.
  • Prerequisites: exact current tech gates from game_core.
  • Unlocks: ship designs, capabilities, orbitals, or per-colony yield bonuses.

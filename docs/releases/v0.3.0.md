## [»] STRATEGIC COMMAND — Sector Governance & Automation v1

*Severity: Notable*

Governors now take orders. The Sector Governance screen (`G`) introduces
per-sector strategic directives and sector-guided build automation — a
framework for delegating local production decisions without surrendering
strategic control.

- **Directive system:** Cycle directives per sector (`D`) — Develop,
  Fortify, Reclaim, Science Focus, and balanced presets guide AI build
  recommendations at the sector level.
- **Sector-guided automation:** Toggle automation (`A`) to let the
  directive engine queue colony builds; manual override still available.
- **Last-turn output reporting:** Each sector reports what was built
  last turn, so automation never becomes a black box.
- **Yield preview:** Sector production, food, science, and credit
  estimates account for directive modifiers.
- **Codex review addressed:** Palette layout corrections and accurate
  sector yield calculations applied post-review.

**Files affected:** 27 files, ~1,870 insertions
**Key modules:** `sector_governance.rs` (new TUI screen), `engine.rs`,
`commands.rs`, `state.rs` (core governance state & validation),
`events.rs` (governance event variants)

## [»] ARCHIVAL RECORDS — Campaign Archives Save Browser

*Severity: Notable*

The Campaign Archives system introduces a dedicated save browser
accessible from the main menu and the `:save` / `:load` command palette.
Players can now browse, inspect metadata, and load campaign histories
without navigating blind.

- **Save browser UI:** Full-screen archive viewer with per-save metadata
  (empire, turn count, galaxy age).
- **Continue flow:** Direct "Continue" path from menu jumps to the most
  recent active campaign.
- **Metadata API:** Save timestamps, version info, and campaign summary
  surfaced in the browser.
- **Persistence:** Backed by the game_save crate's versioned schema
  (CURRENT_VERSION = 36).

**Files:** `archives.rs` (500-line TUI screen), `app.rs` (navigation &
state), `game_save/src/lib.rs` (metadata API)

## [·] INTERFACE — Screen Transition Scaffolding & UI Animation Utils

*Severity: Notice*

A new deterministic animation module (`animation.rs`) provides shared
scaffolding for screen transitions. Includes easing curves, frame
timing, and composable transition states — all seeded from game state,
never from wall-clock time.

- **Animation primitives:** `Easing` enum (Linear, EaseIn, EaseOut,
  EaseInOut), `TransitionState`, composable frame producers.
- **Zero RNG:** All transitions are fully deterministic — replay-safe
  by construction.
- **Integration hooks:** `app.rs` accepts animation state for future
  screen fade, slide, and crossfade effects.

**Files:** `animation.rs` (new), `app.rs`, `app/tests.rs`

## [★★] VISUAL IDENTITY — TUI Foundation Program

*Severity: Historic*

A comprehensive TUI visual overhaul across the entire surface. This is
the single largest UX change in the v0.3.0 cycle — touching every
screen, component, and theme file in the terminal layer.

### Foundation Primitives

- **Shared chrome module:** Unified border, titlebar, and panel
  rendering with splash-screen-grade layout.
- **Footer system:** Consistent contextual key hints and status bar
  across all screens.
- **Header component:** Standardised screen title block with optional
  metadata line.
- **Meter component:** Optimised display-width calculations for
  resource bars — no more overflow or clipping at narrow terminal widths.

### Screen Refresh (Pass 1–3 Campaign)

- **Splash chrome** applied to Sector Map, Sector Overview, and System
  screens — the three most-frequented tactical views.
- **Strategic Map & Overview:** Full chrome and layout refresh with
  consistent spacing, metre alignment, and information hierarchy.
  Sector map gains resizable side-panel and fleet-count indicators.
- **Management Screens:** Colony layout rebuilt (562→ lines rewritten),
  Empire Overview restructured (376→ lines), Research queue view
  expanded, Ship Designer interface reflowed.
- **Diplomacy Screen:** Relationship state display, intel level
  indicators, faction profile rendering — all rebuilt with palette
  consistency.
- **Settings Screen:** Refactored into a themed modal overlay with
  category grouping and live preview.
- **Empire Select:** Streamlined faction picker with emblem rendering,
  trait summary, and palette-adjusted colour swatches.
- **Help Screen:** Consolidated key reference with category grouping.
- **New Game Wizard:** 860-line expansion — emblem display, galaxy
  size visualisation, seed input with randomise option.

### Style Guide & Theme System

- **TUI Style Guide:** New canonical reference document
  (`docs/design/tui-style-guide.md`) defining spacing, colour roles,
  typography, and composition standards for all future screens.
- **Theme `mod.rs` refactored:** Palette roles extracted into
  `theme/palette.rs`; capability detection moved to
  `theme/capability.rs`; gradient support in `theme/gradient.rs`.
- **Accessibility pass:** Tests verify minimum contrast ratios across
  all palette roles (light and dark visual modes). Emblem rendering
  includes foreground-colour-aware fallbacks.
- **Visual Mode support:** All refreshed screens respect
  ASCII/Unicode/Nerd Font modes.
